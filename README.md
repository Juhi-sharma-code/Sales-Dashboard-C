# Sales Dashboard - C Project
B.Tech 3rd Sem - C Language Project

## Project Description
This project is a Sales Dashboard made in C language. It shows sales data like date, product, category, region, orders and revenue. User can view dashboard, total revenue and filter by category.

## Features
- View Sales Data
- Calculate Total Revenue & Total Orders
- Category-wise Filter
- Clean Menu-driven Program

## Technologies Used
- C Language
- Struct, Array, Loop, Functions

## How to Run
1. Download sales_dashboard.c file
2. Open in any C compiler (CodeBlocks / Turbo C / VS Code)
3. Compile and Run
